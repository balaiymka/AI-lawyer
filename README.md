# Портал ЖКХ 24 — AI-юрист по законодательству Республики Казахстан

**Портал ЖКХ 24** — интеллектуальная веб-платформа для предоставления юридической помощи в сфере жилищно-коммунального хозяйства Республики Казахстан.

Система использует искусственный интеллект, технологию RAG и актуальную нормативно-правовую базу РК для анализа обращений, поиска законодательных норм и формирования юридически обоснованных рекомендаций.

## Основные возможности

- **AI-юрист** — анализ жилищных вопросов и подготовка ответов со ссылками на статьи, пункты и подпункты НПА РК.
- **Мультиязычность** — обработка запросов на казахском, русском и смешанном разговорном языке (шала-қазақша).
- **Поиск законодательства** — работа с нормативно-правовыми актами Республики Казахстан.
- **Пошаговые рекомендации** — формирование плана действий для решения юридической проблемы.
- **Генерация документов** — подготовка заявлений, жалоб, обращений и других юридических документов.
- **Юридические калькуляторы** — расчёт пени и кворума собраний собственников.
- **Анализ договоров** — проверка документов и выявление потенциальных юридических рисков.
- **Проверка правовых ссылок** — сопоставление ответов AI с нормативной базой.

## Архитектура системы

Платформа построена на основе технологии **Retrieval-Augmented Generation (RAG)**, которая позволяет искусственному интеллекту формировать ответы с использованием найденных нормативно-правовых документов.

### Принцип работы

1. **Получение запроса.** Пользователь описывает юридическую проблему на казахском, русском или смешанном языке.
2. **Нормализация.** Система определяет язык, категорию обращения и основные юридические факты.
3. **Поиск законодательства.** RAG выполняет семантический поиск соответствующих норм через Qdrant.
4. **Обработка контекста.** Найденные статьи и положения законодательства передаются языковой модели.
5. **Формирование ответа.** AI-юрист подготавливает объяснение проблемы, правовое обоснование и рекомендации.
6. **Проверка ссылок.** Система сопоставляет указанные нормы с сохранёнными источниками законодательства.
7. **Вывод результата.** Пользователь получает структурированный ответ с правовыми основаниями и планом действий.

### Нормативно-правовая база

Система предусматривает работу со следующими источниками:

- Закон РК «О жилищных отношениях».
- Гражданский кодекс Республики Казахстан.
- Гражданский процессуальный кодекс РК.
- Кодекс РК об административных правонарушениях.
- Административный процедурно-процессуальный кодекс РК.
- Другие нормативно-правовые акты, регулирующие жилищные отношения и коммунальные услуги.

Тексты нормативных актов загружаются из информационно-правовой системы **Әділет**, обрабатываются и сохраняются в PostgreSQL для дальнейшего использования в RAG.

## Установка и запуск

### 1. Настройка окружения

Скопируйте файл конфигурации:

```bash
cp .env.example .env
```

Заполните необходимые переменные окружения.

### 2. Запуск инфраструктуры

Для работы необходим установленный Docker.

```bash
docker compose -f infra/docker-compose.yml up -d postgres qdrant redis minio
```

### 3. Установка Backend

Требуется Python 3.12 или выше.

```bash
cd apps/api

python3 -m venv .venv

.venv/bin/pip install -e ".[dev,ingest]"

.venv/bin/playwright install chromium
```

### 4. Запуск Backend

```bash
.venv/bin/alembic upgrade head

.venv/bin/uvicorn app.main:app --reload
```

Backend будет доступен по адресу:

`http://localhost:8000`

### 5. Загрузка законодательства

Загрузка Закона РК «О жилищных отношениях» на казахском и русском языках:

```bash
.venv/bin/python -m ingest fetch ZHO

.venv/bin/python -m ingest load ZHO
```

Проверка загруженной статьи:

`GET http://localhost:8000/v1/library/acts/zho/articles/42`

### 6. Запуск Frontend

Из корневой директории проекта:

```bash
cd apps/web

npm install

npm run dev
```

Веб-приложение будет доступно по адресу:

`http://localhost:3000`

Поддерживаемые языковые маршруты:

- `/ru` — русский язык.
- `/kk` — қазақ тілі.

### 7. Запуск тестов

Из директории `apps/api`:

```bash
.venv/bin/python -m pytest
```

## Цель проекта

Создание доступной интеллектуальной юридической платформы, которая помогает гражданам Республики Казахстан ориентироваться в жилищном законодательстве, понимать свои права и обязанности, находить соответствующие правовые нормы и получать рекомендации по решению вопросов ЖКХ.

**Важно:** ответы искусственного интеллекта носят информационный характер и не заменяют профессиональную юридическую консультацию. Актуальность законодательных норм должна проверяться по официальным источникам.
