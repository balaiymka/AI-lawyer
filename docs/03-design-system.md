# 03. Дизайн-система (по референсам)

Два референса задают две темы одного продукта:

| Референс | Что берём | Где в портале |
|---|---|---|
| **Flight booking (тёмный)** — чёрный фон, графитовые карточки, бледно-голубые (periwinkle) кнопки-пилюли, сегмент-контролы, «маршрут» CDG → DXB, сетка мест | Строгость, контраст, «билет» как метафора маршрута | **Тёмная тема (по умолчанию)**, чат, маршрут дела, калькулятор кворума |
| **Smart home (тёплый glass)** — матовое стекло поверх размытого тёплого фона, янтарное свечение, круглый термостат-циферблат, дуговой слайдер, крупные цифры | Тепло и «дом», понятные крупные показатели | **Светлая тема**, онбординг, дашборд дома (для ОСИ), калькуляторы-циферблаты |

**Шрифт:** `Inter` (Google Fonts, наборы `cyrillic` + `cyrillic-ext` — обязательно проверить глифы ә ғ қ ң ө ұ ү һ і). Крупные цифры калькуляторов — `Inter` 600, `font-variant-numeric: tabular-nums`.

**Радиусы:** карточки 24–28 px, поля 18 px, кнопки — пилюли. **Тени** почти нет; глубина — через слои surface и blur.

## 2. Компоненты: из референса → в портал

| Референс | Компонент портала |
|---|---|
| Сегмент «One-way / Round trip / Multi-city» | **Переключатель роли**: Собственник · ОСИ/ПТ · УК · Юрист; и **KZ / RU** в шапке |
| Поля From / To с круглой кнопкой ⇅ | **Поле «Кто → Кому»** в генераторе документов (заявитель ↔ адресат, кнопка поменять местами) |
| Карточка рейса CDG ─✈─ DXB, «1h 40min» | **«Маршрут дела»**: Претензия ─→ eOtinish / Жилинспекция ─→ Суд; на линии — срок («10 раб. дней» из нормы) |
| Пилюля «Recommended» (зелёная обводка) | Бейдж **«Рекомендуемый путь»**, **«Норма проверена»** (верификатор цитат) |
| Сетка мест A–D с ✓ / ✕ | **Калькулятор кворума**: сетка квартир дома, клик = «за / против / воздержался / не голосовал» |
| Круглый термостат 24 °C с метками 10/15/20/30 | **Циферблат кворума**: текущий % участников, метка «> 50%» (ст. 42 п. 8); для решения подъезда о целевых взносах — «> 2/3» (п. 11) |
| Дуговой слайдер «64% Brightness» | **Шкала перспектив дела** (слабая → сильная позиция) в ответе AI |
| Плитки «Smart Light / Alarm / Wi-Fi» | **Дашборд ОСИ**: «Собрание через 5 дней», «Долги по взносам», «Обращения жильцов», «Капремонт: накоплено» |
| Нижний таб-бар с 4 иконками | Мобильная навигация: **Главная · Чат · Документы · Калькуляторы · Профиль** |
| «Cost: $1099 → Continue» (липкая плашка) | Липкая плашка **«Документ готов → Скачать .docx / .pdf»** и **«Пеня: 48 320 ₸ → Сформировать претензию»** |

## 3. Ключевые экраны

1. **Онбординг / лендинг** — тёплый glass-фон с размытым интерьером, заголовок «Құқығыңыз — бір сұрақта» / «Ваши права — в одном вопросе», подзаголовок «Сұраңыз. Біліңіз. Әрекет етіңіз.», кнопки «Задать вопрос юристу» (accent) и «Войти».
2. **Главная** — «Сәлем, Айгерим» + поле вопроса (можно голосом), сегмент роли, быстрые сценарии-плитки (Затопление, ОСИ не отчитывается, Тариф/счёт, Шум, Перепланировка, Застройщик), «Мои дела» как карточки-билеты.
3. **Чат (Case Analyzer)** — desktop: 3 колонки (дела · чат · панель «Источники» с карточками статей и ссылкой на Adilet). Ответ AI = набор карточек: Кратко → Нормы (раскрываемые цитаты) → Кто отвечает → Перспективы (дуга) → Маршрут дела → Документы (CTA). Mobile: панель источников — bottom sheet.
4. **Документы** — галерея шаблонов → мастер (поля, предзаполненные из чата) → превью → скачать.
5. **Калькуляторы** — пеня (даты, сумма, ставка из справочника, график) и кворум (сетка квартир + циферблат).
6. **Анализ договора** — drag&drop файла → прогресс → список находок с цветом критичности, клик → пункт договора рядом с нормой.
7. **Справочник НПА** — дерево слева, текст статьи, переключатель kk/ru и «редакция на дату».

## 4. Адаптивность и доступность
- Mobile-first: < 768 px — таб-бар снизу, карточки на всю ширину, боковой отступ 16 px; ≥ 1024 px — сайдбар + 3 колонки.
- Контраст текста ≥ 4.5:1 в обеих темах (glass-карточки светлой темы — с плотностью ≥ 0.55 и тёмным текстом).
- `prefers-reduced-motion` отключает blur-анимации и пульсацию циферблатов.
- Крупный режим шрифта (пожилые собственники — значимая аудитория).
